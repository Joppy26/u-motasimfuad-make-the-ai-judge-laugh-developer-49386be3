One funny single-line excuse a developer gives when code breaks in production.

## Entry

> It passed every test in staging, turns out staging was just production in a fake mustache and a trench coat.

## How it works

`main.ts` writes the fixed entry text directly to `/output/entry.txt`. No network, no randomness, no external tools. Run it twice and the output is byte-identical.

```sh
node main.ts
```
